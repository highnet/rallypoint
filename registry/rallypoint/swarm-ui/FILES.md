# swarm-ui registry files

Source paths are relative to `registry/rallypoint/`. One `source -> target` per line.

Notes for the manifest:

- `swarm-ui/app/swarm/swarm.config.ts` is project-owned. The CLI generates it from
  `.rallypoint/swarm.json` (mapping at the top of `swarm-ui/app/swarm/_lib/config-types.ts`)
  and writes it only when the target is absent; it never overwrites it. The source here is
  the neutral template.
- `swarm-ui/standalone/gitignore` is stored without its dot because `npm pack` drops
  `.gitignore` files; it installs as `swarm-ui/.gitignore`.
- `next-env.d.ts` is generated by Next and is not shipped.
- `swarm-ui/README.md` and `swarm-ui/CUSTOMIZE.md` are registry docs, not installed files.
- `swarm-ui/app/swarm/_graph/*` is Swarm Arena's `@rallypoint/swarm-graph` (`swarm-graph/src`),
  without its tests, which run in that repository. The only change is non-null assertions on
  indexed reads, so it compiles under `noUncheckedIndexedAccess` (the standalone dashboard's
  tsconfig). It needs `d3`: the `swarm-ui` item declares `dependencies` / `devDependencies`,
  which the CLI names when the host app lacks them; `swarm-dashboard` lists them in its
  `package.json`.
- `swarm-ui/app/swarm/_lib/animal-icons.ts` is Swarm Arena's `shared/src/animalIcons.ts`,
  copied verbatim: game-icons.net silhouettes, CC BY 3.0, credited under the fleet graph.
  `animals.ts` assigns them to agents and depends on their order.
- `swarm-ui` declares `dependencies: {"@supabase/realtime-js": …}` for `_components/live.tsx`;
  the CLI prints the `npm install` line when the host app lacks it. `swarm-dashboard` carries it
  in `swarm-ui/standalone/package.json` instead.
