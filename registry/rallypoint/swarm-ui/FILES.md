# swarm-ui registry files

Source paths are relative to `registry/rallypoint/`. One `source -> target` per line.

Notes for the manifest:

- `swarm-ui/app/swarm/swarm.config.ts` is project-owned. The CLI generates it from
  `.rallypoint/swarm.json` (mapping at the top of `swarm-ui/app/swarm/_lib/config-types.ts`)
  and writes it only when the target is absent; it never overwrites it. The source here is
  the neutral template.
- `swarm-ui/standalone/gitignore` is stored without its dot because `npm pack` drops
  `.gitignore` files; it installs as `swarm-ui/.gitignore`.
- `next-env.d.ts` is generated by Next and is not shipped.
- `swarm-ui/README.md` and `swarm-ui/CUSTOMIZE.md` are registry docs, not installed files.
