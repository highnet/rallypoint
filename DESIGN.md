# Rallypoint Visual System

## Theme

A premium tabletop campaign map: forest felt, carved parchment routes, molded role tokens, metal fasteners, and restrained magical illumination. It should feel like a systems-thinking board game photographed with care.

## Color

Colors use OKLCH tokens. Daylight uses pale sage and forest ink. Night uses deep green felt and warm parchment. Vermilion, cobalt, amber, violet, and moss identify roles and stages.

## Typography

Geist Sans carries all operational text. A Palatino-style serif is reserved for campaign titles and short display phrases. Geist Mono is used only for commands, file paths, and machine-readable details.

## Components

Buttons feel pressed into the table through tight shadows and small radii. Panels are parchment sheets or inset wells, never generic floating cards. Role markers are distinct shapes, not repeated icon circles.

## Layout

The hero uses an asymmetric 42/58 composition. Later sections alternate between generous narrative copy and dense protocol artifacts. Mobile stacks the table below the message and preserves the loop as a horizontally complete diagram.

## Motion

The route draws once, tokens settle sequentially, and active handoffs pulse forward. Hover lifts tokens by a few pixels. Reduced motion removes travel and keeps immediate state changes.
