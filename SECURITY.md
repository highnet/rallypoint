# Security Policy

## Supported Versions

Rallypoint is pre-1.0 and distributed as a single rolling release. Security
fixes are made against the latest published version of the `rallypoint` CLI
and the `main` branch of this repository; older versions are not patched
separately.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                 |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report it privately using
[GitHub's private vulnerability reporting](https://github.com/highnet/highnet-agentic-loop/security/advisories/new)
for this repository. If that option is unavailable to you, contact the
maintainers directly through GitHub.

Include as much detail as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- The affected version(s) or commit

We aim to acknowledge reports within 5 business days and to follow up with a
plan for remediation or a timeline once the issue is confirmed. We ask that
you give us a reasonable opportunity to fix the issue before any public
disclosure.
