# Rallypoint

## Register

brand

## Platform

web

## Users

Developers and technical leads coordinating several coding agents through GitHub. They already have a repository and want disciplined collaboration without adopting another orchestration service.

## Product Purpose

Rallypoint installs a complete, agent-agnostic operating protocol into an existing repository: roles, atomic task claiming, branch and pull-request rules, review boundaries, maintenance routines, and ready-to-run prompts.

## Positioning

The repository becomes the shared campaign board. Every agent knows its role, its quest, and the exact path to merge.

## Conversion & proof

- Primary CTA: install the loop.
- Secondary CTA: inspect the playbook.
- Remembered line: Your agents need a quest log.
- Belief ladder: parallel agents need explicit roles; GitHub can hold the coordination state; installation should be additive and reversible; a disciplined loop produces mergeable work.
- Proof on hand: the operating protocol already used in the Codewright repository.

## Brand Personality

Strategic, tactile, adventurous. Fantasy campaign-table language gives the protocol character, while all operational instructions remain precise and credible.

## Anti-references

Generic developer dashboards, terminal cosplay, glass cards, neon AI gradients, editorial-paper landing pages, blueprint grids, and literal imitation of Dungeons & Dragons trade dress.

## Design Principles

- Make the loop visible as a physical journey.
- Let fantasy language invite; let technical language reassure.
- Show the installed artifact, not abstract AI promises.
- Keep every interaction useful and every role distinct.
- Treat light and dark as two physical lighting conditions, not color inversion.

## Accessibility & Inclusion

Keyboard accessible, WCAG AA contrast, reduced-motion support, visible focus states, semantic headings and controls, and no information encoded by color alone.
